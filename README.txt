CHLOE CHAN PORTFOLIO — GITHUB PAGES

1. Create a PUBLIC repository on GitHub (e.g. chloe-portfolio).
2. Choose Add file > Upload files.
3. Drag the CONTENTS of this folder (index.html, other .html files, assets folder, .nojekyll). Do not upload the enclosing chloe-portfolio folder.
4. Commit changes.
5. Settings > Pages > Build and deployment > Deploy from a branch. Select main and /(root), then Save.
6. Visit https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ once published.

Important: The original supplied CV explicitly says this is a fictional sample person and experience. The site is a demonstration. Replace fictional contact details and CV before publishing a real personal portfolio.

No build process required. All internal links are relative, compatible with GitHub project Pages. Fonts load from Google Fonts (requires internet).
